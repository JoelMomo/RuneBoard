# Bundled keyboard fonts

RuneBoard bundles optional fonts for keyboard-label customization.

All bundled fonts are distributed under the SIL Open Font License (OFL):

- Inter — Google Fonts `ofl/inter`
- Atkinson Hyperlegible — Google Fonts `ofl/atkinsonhyperlegible`
- JetBrains Mono — Google Fonts `ofl/jetbrainsmono`
- Space Grotesk — Google Fonts `ofl/spacegrotesk`

The corresponding upstream `OFL.txt` files are packaged under:

`app/src/main/assets/font_licenses/`

The default `System` option uses Android's platform typeface.
